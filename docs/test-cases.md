## Reproduce the checks

From the repository root:

```sh
npm ci
npx playwright install chromium
npm run lint
npm run build
npm test
```

Test source: [`client/tests/login.spec.ts`](../client/tests/login.spec.ts). Each test title includes the corresponding test-case ID. The two configured browser projects run the same ten scenarios for 20 checks total. Use `npm test -- --grep SP1-4` to run only the validation scenarios.

## Manual review

1. Start `npm run dev`, then open the printed local URL.
2. Use the matrix above to repeat the login and dashboard flows.
3. On a narrow viewport, open the navigation menu, choose Food diary, and confirm the menu closes. Open it again to sign out.
4. Use Tab and Shift+Tab to reach the email field, password toggle, sign-in button, demo button, sidebar controls, and sign-out button; confirm the focus indicator is visible. Submit a form error and confirm focus moves to the invalid field.
5. Compare the login and dashboard against the reference: light background, rounded white panels, cyan/coral nutrition cards, clear spacing, and a compact sidebar.

Screenshots are available in the layout test's directories under `client/test-results/`; the HTML test report is at `client/playwright-report/index.html`. These generated artifacts are excluded from Git.
